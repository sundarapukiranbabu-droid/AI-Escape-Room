🔐 AI Escape Room – The Mystery of the Locked Library

An interactive AI-powered Escape Room game developed using Python, Streamlit and Google Gemini as part of the Master’s in Data Science programme at the University of Europe for Applied Sciences.

🎮 Live Application

Play the AI Escape Room here:

https://ai-escape-room-ocanzniiwma8ipwvzjbymn.streamlit.app/

The application allows players to explore a locked library, discover clues, solve puzzles, manage inventory and escape before the timer expires.

📌 Project Overview

The project has two development versions.

Version 1 – Interactive AI Escape Room

* Interactive web-based game.
* Gemini-powered AI interaction.
* Natural-language player interaction.
* Clues and puzzles.
* Conversation-based gameplay.
* Restart functionality.

Version 2 – Reliable AI Escape Room

* Structured game-state management.
* Python-based puzzle validation.
* Inventory management.
* Difficulty selection.
* Countdown timer.
* Score and hint management.
* Validation of player actions.
* Protection against unsupported AI-generated progress.

🛠️ Technologies Used

* Python
* Streamlit
* Google Gemini API
* Google GenAI
* Streamlit Auto Refresh

▶️ Run Locally

1. Clone the repository

git clone https://github.com/sundarapukiranbabu-droid/AI-Escape-Room.git

2. Install dependencies

pip install -r requirements.txt

3. Run Version 2

streamlit run AI_Escape_Room_Complete_Project/version_2/AI_Escape_Room_Version2_Validated.py

4. Gemini API

Enter your Gemini API key in the application if prompted. Never publish your API key in this repository.
